# ข้อมูลลงเวลาเข้าระบบอัตรากำลังรายเวร

## ทางหลัก: Flood2026-site-api (hosoffice + ระบบลงเวลา HIK) — ทำให้แล้ว

- หน้า `flood/manpower` เรียก `v1/attendance` ของ **Flood2026-site-api** (โฟลเดอร์ข้างเคียง `../Flood2026-site-api`) เองอัตโนมัติ
  ทุก `MP_SYNC_MINUTES` นาที (ค่าเริ่มต้น 5) เมื่อเปิดหน้าวันนี้/เมื่อวาน หรือกดปุ่ม **ดึงข้อมูลลงเวลา** (ย้อนหลังได้ 30 วัน)
- ทุกครั้งที่ซิงก์ ระบบลบแถว `source = 'hosoffice'` ของวันนั้นแล้วสร้างใหม่ทั้งหมด → แก้การจับคู่หน่วยงานแล้วกดดึงใหม่ได้เลย
- **จับคู่หน่วยงาน**: หน้า `flood/manpowerUnits` ช่อง "หน่วยงานใน hosoffice" (ชื่อหรือรหัสหน่วยงาน คั่นด้วย ,) — ว่าง = ใช้ชื่อหน่วยงานของ Flood ตรงตัว
  หน่วยงานที่มีคนสแกนแต่ยังไม่จับคู่ แสดงเป็นรายการสีเหลืองบนหน้าเดียวกัน (7 วันล่าสุด)
- **พยาบาลวิชาชีพ**: ตำแหน่งที่ตรง `MP_RN_REGEX` (ค่าเริ่มต้น `พยาบาลวิชาชีพ`) = `RN` นับเทียบกรอบ · อื่น ๆ = `OTHER` แสดงแยก
- สถานะการซิงก์แต่ละวันอยู่ในตาราง `flood_mp_sync`
- ผู้ใช้: หน้า `flood/settingsUsers` → **นำเข้าข้อมูลผู้ใช้จาก API** (HR_USERNAME = ชื่อผู้ใช้, เข้าสู่ระบบด้วยรหัสผ่าน hosoffice) / **ทดสอบการเชื่อมต่อ**

## ทางเสริม: เขียนตรงเข้าตาราง (ระบบอื่น)

หน้า `flood/manpower` นับจำนวน **พยาบาลวิชาชีพ (RN)** ที่ขึ้นเวรจากตาราง `flood_mp_checkin` แล้วเทียบกับกรอบใน `flood_mp_unit`
ระบบลงเวลาแค่เขียนการลงเวลารายคนเข้าตารางนี้ (ฐานข้อมูลเดียวกับ Flood2026 คือ `db_flood`) หน้าเว็บจะเห็นทันทีเมื่อรีเฟรช (หน้าระบบเจ้าหน้าที่รีเฟรชเองตามรอบที่ตั้งไว้)

## ตาราง `flood_mp_checkin`

| คอลัมน์ | ชนิด | ความหมาย |
|---|---|---|
| `unit_code` | VARCHAR(30) | รหัสหน่วยงาน ต้องตรงกับ `flood_mp_unit.unit_code` (ตารางด้านล่าง) ตัวพิมพ์ใหญ่ |
| `work_date` | DATE | วันที่ของเวร |
| `shift` | CHAR(1) | `M` เช้า 08:00–16:00 · `A` บ่าย 16:00–24:00 · `N` ดึก 00:00–08:00 **ของวัน work_date** |
| `emp_code` | VARCHAR(30) | รหัสพนักงาน ใช้นับไม่ซ้ำคนต่อเวร |
| `emp_name` | VARCHAR(150) | ชื่อ-สกุล (แสดงในรายชื่อผู้ลงเวลา) |
| `staff_type` | VARCHAR(10) | `RN` = พยาบาลวิชาชีพ (**นับเทียบกรอบ**) · อื่น ๆ เช่น `PN` `NA` แสดงแยก ไม่นับ |
| `checkin_at` | DATETIME | เวลาที่สแกนเข้า |
| `source` | VARCHAR(30) | ค่าตั้งต้น `site-api` |

คีย์ไม่ซ้ำ: `(unit_code, work_date, shift, emp_code)` — ส่งซ้ำได้ ไม่เกิดแถวซ้ำ

### ตัวอย่างการเขียน

```sql
INSERT INTO flood_mp_checkin (unit_code, work_date, shift, emp_code, emp_name, staff_type, checkin_at, source)
VALUES (:unit_code, :work_date, :shift, :emp_code, :emp_name, :staff_type, :checkin_at, 'site-api')
ON DUPLICATE KEY UPDATE emp_name = VALUES(emp_name), staff_type = VALUES(staff_type),
    checkin_at = LEAST(COALESCE(checkin_at, VALUES(checkin_at)), VALUES(checkin_at));
```

### การจับเวรจากเวลาสแกน (ถ้าระบบลงเวลาไม่มีข้อมูลเวรเอง)

แนะนำให้ใช้เวรจากตารางเวร (roster) เป็นหลัก ถ้าไม่มี ให้เดาจากเวลาสแกนโดยเผื่อมาก่อนเวร 1 ชั่วโมง:

| เวลาสแกน | shift | work_date |
|---|---|---|
| 07:00–14:59 | `M` | วันเดียวกัน |
| 15:00–22:59 | `A` | วันเดียวกัน |
| 23:00–23:59 | `N` | **วันถัดไป** |
| 00:00–06:59 | `N` | วันเดียวกัน |

## ข้อมูลที่เจ้าหน้าที่กรอกเอง

ถ้าในหน้าเว็บมีคนกรอกจำนวนเอง (ตาราง `flood_mp_count`) ระบบใช้ค่านั้นแทนจำนวนจากการลงเวลาของหน่วย/เวรนั้น
กด "ลบค่าที่กรอก" เพื่อกลับไปใช้ข้อมูลลงเวลา
