# SK Flood — ระบบช่วยเหลือผู้ประสบภัยน้ำท่วม จังหวัดสระแก้ว

ระบบของโรงพยาบาลสมเด็จพระยุพราชสระแก้ว สำหรับช่วงน้ำท่วม

- **ประชาชน**: ดูแผนที่พื้นที่น้ำท่วม · แจ้งจุดน้ำท่วม · ขอความช่วยเหลือ · ติดตามคำขอ
- **เจ้าหน้าที่**: ประกาศพื้นที่บนแผนที่ · ตรวจรายงาน · รับเรื่อง/มอบหมายทีม (ใบงาน) · ทะเบียนกลุ่มเปราะบางพร้อมเตือนเมื่ออยู่ในพื้นที่ประกาศ
- **ผู้ดูแล**: ผู้ใช้งาน · ผู้ใช้งานออนไลน์ · ประวัติการเข้าใช้งานและการแก้ไขข้อมูล

PHP MVC แบบเดียวกับระบบ COC · MySQL/MariaDB `db_flood` บน 192.168.0.18

วิธีติดตั้งและรายละเอียดทั้งหมดอยู่ใน **INSTALL.md**
